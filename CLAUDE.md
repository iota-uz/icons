# `github.com/iota-uz/icons` — agent notes

This repo packages **Phosphor Icons** as **[`templ`](https://github.com/a-h/templ)** components for Go apps.

## Quick commands (local dev)

- **Install deps**

```bash
make deps
```

- **Download upstream SVGs (ignored by git)**

```bash
make download
```

- **Regenerate templ sources + Go code**

```bash
make generate
```

- **Sanity check**

```bash
go test ./...
```

Notes:
- `make download` uses `wget`. On macOS you may need `brew install wget` (or adjust the Makefile locally if desired).
- `templ` CLI is expected at version **v0.3.819** (see `go.mod` / `README.md`).

## What’s source vs generated

- **Upstream inputs (not committed)**
  - `phosphor-icons/`: downloaded Phosphor ZIP extraction (ignored via `.gitignore`)

- **Generator (hand-edited)**
  - `cmd/generate/main.go`: reads SVGs from `phosphor-icons/SVGs/**` and produces templ sources + `list.go`

- **templ sources (generated by `cmd/generate`)**
  - `phosphor/*.templ` (except `phosphor/base.templ`)
  - These are grouped by icon “prefix” (first `-` segment) to keep file sizes manageable.

- **Shared base (hand-edited)**
  - `phosphor/base.templ`: defines `Variant`, `Props`, and the shared `svg(props)` wrapper component

- **Go output from templ compiler (generated)**
  - `phosphor/*_templ.go`: generated by `templ generate` (header says “Code generated by templ - DO NOT EDIT.”)

- **Icon registry (generated by `cmd/generate`)**
  - `phosphor/list.go`: maps icon function names to `Icon` for dynamic lookup

## Editing rules (important)

- **Do not edit** `phosphor/*_templ.go` (templ output). Always edit the corresponding `.templ` file (or generator) and rerun `templ generate`.
- **Do not hand-edit** generated icon `.templ` files long-term. If you need to change SVG normalization or grouping, change `cmd/generate/main.go` and rerun `make generate`.
- **Keep variants consistent**:
  - `cmd/generate/main.go`’s `variants` map keys must match the `Variant` const names in `phosphor/base.templ` (`Regular`, `Filled`, `DuoTone`, `Thin`, `Bold`, `Light`).

## Common tasks

- **Change default SVG wrapper behavior** (e.g., default size, classes, attributes):
  - edit `phosphor/base.templ`, then run `templ fmt . && templ generate`

- **Change how SVGs are cleaned/normalized** (e.g., fill handling):
  - edit `cmd/generate/main.go` (see `extractSVGContents` / `addFillAttribute`), then run `make generate`

- **Add/rename variants**
  - update both `phosphor/base.templ` and `cmd/generate/main.go`’s `variants` map, then regenerate
